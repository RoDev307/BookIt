<h2>📅 Descripción del Proyecto</h2>
<p><b>BookIt</b> es una solución web integral diseñada para la gestión operativa, agendamiento de citas y control de infraestructura de comercios locales. Desarrollada como una plataforma multi-tenant, permite a múltiples establecimientos administrar sus servicios, especialistas y reservas de manera eficiente, optimizando el flujo de atención y evitando colisiones cronológicas.</p>

<h2>🚀 Características Técnicas</h2>
<ul style="list-style-type: none; padding: 0;">
    <li>✅ <b>Multi-tenant SaaS:</b> Gestión centralizada para múltiples establecimientos.</li>
    <li>✅ <b>Agendamiento Inteligente:</b> Módulo de recepción con validación horaria estricta (08:00 - 17:00).</li>
    <li>✅ <b>Calendario Operativo:</b> Visualización en tiempo real mediante FullCalendar.js.</li>
    <li>✅ <b>Reportería PDF:</b> Generación de comprobantes individuales y reportes masivos (Semanal/Mensual).</li>
    <li>✅ <b>UI Híbrida:</b> Interfaz profesional con soporte nativo de modo claro y oscuro.</li>
</ul>
